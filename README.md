# Minimal Tower Defense for macOS

A tiny tower defense game packaged as a macOS app with Tauri.

## Download Page

This repo includes a static download page:

- `index.html`
- `styles.css`
- `downloads/Minimal Tower Defense_0.1.0_aarch64.dmg`

To publish it with GitHub Pages:

1. Push this repo to GitHub.
2. Open the repo settings.
3. Go to Pages.
4. Set the source to deploy from the `main` branch root.
5. Share the Pages URL once GitHub finishes deploying.

## macOS Note

This is currently an unsigned test build. macOS may block it on first launch.
Right-click the app and choose Open to run it during testing.
